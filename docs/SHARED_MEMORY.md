# 家庭与团队共同记忆

这一版支持在当前电脑上创建多个家庭／团队空间，通过独立账号确认操作人。个人记忆、声纹和空间账号分别管理：切换个人档案、识别到某个声纹，都不会获得空间权限；个人内容不会自动共享。

## 开始使用

1. 启动项目并刷新 `http://127.0.0.1:8765`，展开页面下方「家庭与团队 · 后台管理」。
2. 每位成员注册自己的空间账号，再登录。口令长度 10–128 个字符；账号名称唯一，不要求与个人档案同名。正式数据库不预置演示账号或默认口令。
3. 创建「家庭」或「团队」空间，创建者是管理员。
4. 在「成员与角色」输入已经注册的账号名称，添加为编辑成员或只读成员。不同空间的角色独立。
5. 填写共同记忆，选择可见成员和修改权限，可补事件日期、来源说明；点击「预览发布范围与内容」，核对并勾选后确认发布。
6. 在「根据这个空间的记忆提问」中提问，可展开本次提供给模型的资料。上方原个人对话继续使用个人记忆，不会自动混入共同记忆。
7. 使用完点击「锁定并退出空间账号」。刷新网页后需重新登录；个人档案变化（包括声纹切换）会锁定空间账号。

## 记忆归属和权限

每条共同记忆归属于一个空间，记录不可变的原作者、最近修改人、保存／更新时间、事件日期和来源说明。家庭／团队类型不改变权限规则。

| 操作 | 管理员 | 编辑成员 | 只读成员 |
|---|---|---|---|
| 查看记忆、用于空间问答 | 空间内全部 | 仅本人可见 | 仅本人可见 |
| 发布记忆 | 可以 | 可以 | 不可以 |
| 修改正文、事件日期、来源 | 全部 | 本人发布的；或可见且允许编辑成员修改的 | 不可以 |
| 调整可见范围／修改策略、删除 | 全部 | 本人发布的 | 不可以 |
| 查看修改历史 | 全部 | 本人发布的 | 本人曾发布的 |
| 添加／移除成员、调整角色、删除空间 | 可以 | 不可以 | 不可以 |

作者离开空间后也不能访问；作者被降为只读后不能编辑或删除。管理员角色目前固定为创建者，暂不支持转让或设置第二位管理员。

可见范围有两种：

- **全体成员**：当前与以后加入的成员均可查看。
- **指定成员**：仅勾选的现有成员，以及仍属于空间的作者和管理员可查看。默认选择此范围。管理员始终能看空间内全部记忆；不适合保存需要对管理员保密的内容。

修改权限也有两种：仅作者和管理员，或允许可见的编辑成员修改。后一种仅开放正文与事件信息编辑，不允许其他编辑成员改权限、删记忆或查看历史。这样扩大当前内容的可见范围时，不会同时暴露旧的私密版本。

移除成员会立即撤销服务端空间访问及其指定可见授权；重新添加不会恢复旧的指定授权，作者身份例外（重新加入后能查看自己发布的记忆）。已经看过、复制过的内容无法追回。页面空闲时每 30 秒刷新权限；所有请求都即时重新检查，不能靠隐藏按钮绕过服务端权限。

## 发布确认、历史和问答

- 新建和编辑都先预览，展示归属、作者、本次操作人、可见成员、修改权限以及前后内容。内容／成员／权限在此后改变，会要求重新预览。预览 10 分钟有效、仅使用一次，与账号和空间绑定。
- 对相反喜好等有限规则识别的可能冲突，额外勾选确认后才发布；提示只比较当前账号可见的记忆，不暴露隐藏记忆，也不自动覆盖冲突记录。这不是完整语义冲突识别。
- 新建和每次修改记录历史，正文、权限和历史在同一事务提交。每条展示最近 100 次及总数。单条删除现改为移入回收站，保留原文和历史；删除空间会删除共同记忆、历史、成员关系及该空间回收站和恢复记录，保留个人记忆、声纹及账号。旧备份需另外管理。
- 共同问答先验证登录与成员身份，再过滤可见记忆，按文字相似度选择最多 8 条、正文总计不超过 2200 字作为背景，不使用个人资料或个人聊天历史。生成结束还会复核空间版本与访问权限；期间发生变化会要求重新提问。
- 共同问答为单次文字问题，不保存会话上下文，不自动写入记忆；支持停止生成。若选云端模型，当前问题和筛选后的可见资料会发送给所选服务。显示的资料表示本次传给模型的背景，不等于模型对每句话都做了严格引用。

## 存储和本机使用边界

沿用 `data/assistant.sqlite3`，新增 `shared_accounts`、`shared_sessions`、`shared_spaces`、`shared_members`、`shared_memories`、`shared_audience`、`shared_history` 七张表。原有个人表不迁移为共享内容。每个空间最多 200 条记忆、每条 1200 字、100 位成员；每账号最多创建 20 个空间，本机最多 100 个空间账号。

口令使用随机盐和 scrypt 哈希，数据库保存哈希而非明文。登录令牌随机生成，数据库只存摘要，8 小时失效，每账号最多 5 个会话；页面仅在运行内存中保存令牌和共同记忆，不写入浏览器聊天缓存。修改口令需原口令，并撤销该账号全部会话。目前没有忘记口令找回或账号注销界面。

服务仍仅监听本机 `127.0.0.1`，这不是可直接开放公网的多人服务。拥有本机系统账号和数据库文件的人仍可直接读取数据，SQLite 未加密；个人档案选择也仍是本机个性化功能，并非受空间账号保护的私人保险箱。跨电脑访问、邀请链接、HTTPS 和完整账号恢复需另行实现。

共同记忆已接入按后台选定空间进行的语音查询、保存、修改与口头确认，详见下文。尚未实现多人声纹自动切换登录账号、个人记忆一键共享（资料 JSON 读取已支持，见文末）。可先使用本机成员轮流登录验证流程，再扩展联网协作。

## 共同记忆语音交互

日常查询、保存和修改通过现有麦克风、唤醒与朗读完成；网页中的「家庭与团队 · 后台管理」用于账号、成员和权限配置。开启后后台管理会自动收起，主对话区显示本次语音交互，不保存到个人聊天缓存。

### 一次性准备与每次开启

1. 在「用户与记忆」选择本人已登记声纹的个人档案。
2. 登录自己的空间账号，选择家庭或团队空间。账号登录决定权限；选档案和声纹匹配不能代替登录。
3. 默认使用公开播放，仅查询或修改全体成员可见的已有记忆。如需查询指定成员记忆，先使用耳机或确认独处，再勾选私密收听。
4. 点击「开启共同记忆语音」，允许麦克风。程序启用声纹核对与语音唤醒，播报当前空间及账号。当前每次绑定一个账号、一个档案和一个空间，30 分钟有效；切换空间或操作者先退出，再重新配置。
5. 唤醒词仍是「你好小伴」。唤醒后说出问题或操作，也可以使用「点击说话」。声纹开关在此模式中保持开启。

当前仍由浏览器负责录音和播放：网页可以退到后台，但需保持页面打开、电脑不休眠；还不是关闭浏览器也能独立运行的设备服务。macOS 有 TTS，Windows／Linux 尚不能完成这一语音闭环。开启前要求 ASR、声纹、唤醒和 TTS 可用。

### 可以怎么说

| 意图 | 示例 | 处理 |
|---|---|---|
| 查询 | 我们家庭周末有什么安排？ | 仅检索当前空间与当前播放模式允许的资料后回答 |
| 新建 | 记住，家庭周末活动安排在周日下午三点去公园 | 复述内容、空间、可见范围、修改权限，尚不写入 |
| 调整可见范围 | 仅让甲可见；或全体成员可见 | 使用空间账号名称匹配，生成新的播报与确认，旧确认失效 |
| 修改 | 把家庭周末活动改成家庭周末活动安排在周六下午三点去公园 | 以原文关键词找唯一可见记忆，复述新内容，保留原作者与权限 |
| 确认新建 | 我确认保存这条共同记忆 | 完整播报结束后才可确认写入 |
| 确认修改 | 我确认修改这条共同记忆 | 完整播报结束后才可确认修改 |
| 取消 | 取消；或取消保存这条共同记忆 | 丢弃待确认草稿 |
| 退出 | 退出共同记忆语音 | 关闭此模式与其监听，恢复普通个人对话界面 |

新建默认全体成员可见、仅作者和管理员修改，必须经口头确认。也可一句话说「记住，活动安排内容，仅让甲可见」。作者和管理员仍始终可见。指定名称必须是该空间的账号名称；同名个人档案不代表成员账号。

建议说完整确认句，短短「确认保存」可能达不到声纹识别需要的有效语音长度。识别不确定或换成另一个说话人时，锁定共同模式，不沿用上一人的账号回答。取消／退出只会减少访问或丢弃草稿，短句声纹不确定也可取消，不授予读取或写入权限。

### 确认规则

- 每个操作都依靠服务端真实 ASR 结果生成的一次性语音凭证；输入框文字、客户端自报的说话人、旧录音凭证不能确认写入。
- 播报完整结束后才开启确认，并自动收听下一句，无须再次唤醒。确认时限 90 秒；自动收音静音约 8 秒会结束，本轮待确认草稿随之取消。
- 打断、取消、新问题、无效范围变更、账号／空间变化、声纹重新登记和权限变化会阻止旧确认生效。播放失败或未完整播放不能确认；已经完成提交的记忆需另行修改，打断不撤销已提交的数据。
- 一般的「好的」「是的」不会写入，会再次要求明确的完整确认句。
- 可能冲突时，播报要求「我确认保存这条共同记忆并保留冲突」或相应修改句；保留已有冲突记录，不自动替换其他条目。
- 修改找不到唯一匹配时请补充原文关键词，或到后台选择记录；不会猜测目标。此版本使用明确句式与有限规则处理写入，不依赖大模型自行决定保存。
- 语音不管理成员、不删除记忆、不修改编辑权限、不切换空间；这些操作保留在后台。语音改变可见范围也遵循原作者／管理员权限，普通编辑成员只能修改允许编辑的正文。
- 公开模式不会把指定成员的已有记忆放进查询、修改目标或冲突比较中；你主动口述的新草稿会被复述，因此现场有人时也不要口述需要保密的内容。
- 默认只回答当前问题，不把语音共同对话加入个人聊天历史；切换账号或退出会清空本次显示。后台文字问答与个人聊天仍可在退出语音模式后使用。

语音凭证、草稿与确认状态只在服务内存中保存，服务重启后失效；确认后的记忆和历史仍保存到原 SQLite 的共同记忆表，不更改个人声纹与个人表。

本阶段验证包括状态机、HTTP 接口、前端播报结束／打断回调，以及合成音频经过真实 ASR、声纹、TTS、本地 Qwen 的保存→确认→修改→确认→查询→取消链路。合成音频测试不代替真人、ReSpeaker 回声和多人交替实测。

## 历史聊天与活动资料：先预览，再导入

入口：展开「家庭与团队 · 后台管理」，登录空间账号并选择空间，再展开「资料整理与导入 · 先预览，再保存」。管理员和编辑成员可以使用；只读成员不能导入。

1. **添加资料**：可混合选择文件，也可添加多份粘贴文字。支持 TXT、MD、UTF-8／GB18030 文字、CSV、JSON 聊天导出、Word DOCX、PDF、PNG／JPG。
2. **核对原文**：每份资料显示名称、读取文字和遗漏提示；可修正识别错误、删掉不应共享的内容或移除整份资料。原文有改动时，旧候选和旧确认会失效。
3. **生成候选**：默认按空行分段，不调用模型；长段落每 1000 字拆分。也可选择当前模型进行 AI 提炼。AI 按短片段处理全部输入，引用有效的原文编号，页面展示程序取出的原文摘录。编号有效不代表结论正确，仍须核对语义和遗漏。
4. **编辑与选择**：逐条修改记忆、状态、日期和来源说明，取消不需要的条目。本批统一设置可见成员和修改权限；需要不同权限的资料可分批导入，或导入后逐条调整。默认仅作者和管理员可见、可修改。日期不明确时留空，不按导入日期猜测事件日期。
5. **最终预览**：显示实际归属、导入账号、每条内容、状态、来源、日期、可见成员、修改权限、跳过的重复数量及可能冲突。勾选确认后才新增正式记忆；冲突需要另行勾选。返回修改会撤销旧预览。
6. **导入完成**：整批在一个 SQLite 事务中保存，每条记录都有创建历史；可以从列表查看、编辑，或使用已有共同记忆语音查询。作者是当前登录账号，聊天中的发言者不会自动成为空间账号。

### 格式与运行环境

- 每份文件最多 4 MB；PDF 最多 20 页；每批最多 10 份资料、30000 字原文、40 条候选；每条正式记忆最多 1200 字，每空间仍为 200 条。超限提示拆分，不静默截断。
- Mac 使用 Apple Vision 本机识别图片和扫描页，PDFKit 读取 PDF。首次使用自动编译识别小工具，需要 Xcode Command Line Tools（可运行 \`xcode-select --install\` 安装）；本机已完成合成中文图片和扫描 PDF 验证。识别与文件读取不调用云端。
- Windows／Linux 文字 PDF 使用 pypdf；图片与扫描页尚未接入离线 OCR，请先转换为文字再粘贴。Windows 尚未完成真机验收。
- DOCX 读取正文及表格文字，不读取图片、批注、页眉页脚。PDF 中的复杂表格、带文字页面里的嵌入图片、排版顺序可能遗漏。图片识别有人名、数字、断行错误的可能；模糊长图请分段上传清晰原图。
- 旧版 DOC、微信加密聊天数据库、压缩包、音视频不直接读取；请导出为支持格式。JSON／CSV 保留文字字段供预览，未对每种聊天平台做专用字段适配。
- AI 整理使用当前配置的对话模型。本地 Ollama 增加 JSON 结构约束；兼容云端接口使用提示词和严格结果校验。远端地址必须先勾选同意发送原文。格式错误、无效引用、截断、服务故障都不会写入，可以重试或改用按段落整理。

### 资料、权限与取消

上传文件只在临时目录中解析，结束后清理。候选不写入个人聊天缓存；最终预览有效期 10 分钟。切换空间、切换账号或退出会清空页面草稿；刷新页面也不会恢复未导入资料。正式保存确认的内容、状态、事件日期、来源说明、作者、权限及历史。勾选保留原文依据时，还会保存完整文字快照及引用位置；未勾选则不保存。原始图片或文档附件不归档，请自行保留原件。具体权限见下文。

重复检查使用去除首尾空白后的全文相等，仅比较本账号可见的已有记忆和本批内容；不会为了去重泄露不可见记忆。语义近似和不同措辞不保证去重。冲突检查排除已过时的已有记录，并沿用现有有限规则，不是全面的活动安排矛盾检测。只新增，不自动合并或覆盖旧记忆。

确认绑定当前登录会话和空间版本，重复点击不能重复提交；成员权限或空间内容变化后要求重新预览。数据库写入失败会整批回滚。读取／整理可停止；确认请求已经被服务器提交后，停止网页或退出不能撤销已完成导入，先刷新列表核对。

未实现：跨设备后台协作、原文件长期归档、任意聊天格式解析、导入批次一键撤销。

## 来源追溯与记忆状态

本功能用于家庭／团队共同记忆，个人记忆保持原有流程。

### 保留与查看原文依据

在「资料整理与导入」生成候选后，勾选「保留原文依据，便于日后追溯」。最终预览会显示要保留的相关摘录、原文行号／可识别的 PDF 页码，以及谁能查看。确认导入时，记忆、状态、原文依据和创建历史在同一个事务中保存，任何一部分失败都会回滚。

保存的是**整理时核对过的完整文字快照**，可能包含 OCR 结果、格式转换和用户修订，不是原始图片、Word 或 PDF 附件。原文快照记录资料名称、文字摘要哈希、对应摘录的位置、导入时的记忆正文和保存时间。资料原件仍请自行保管；PDF 页码来自读取时的页标记，不是独立真实性认证。

- 「查看原文依据」展示与该记忆对应的摘录、行号和页码（如有），任何当前有权查看该记忆的成员可以查看。
- 完整原文只允许仍在空间内的原作者和管理员查看，需另外点击「查看完整原文文字」。普通编辑或只读成员不会因为能看一条摘要而获得整份原文。
- 摘录跟随记忆的当前可见范围；修改范围前会提示这一点。作者／管理员查看全部原文的权限不随记忆扩大分享而扩大。
- 原文依据不会自动进入模型问答上下文或个人聊天缓存。关闭依据面板、切换空间／账号、退出，或刷新检测到空间版本变化，会清空页面展示；服务器每次读取重新检查权限。
- 修改正文不会覆盖原文快照。页面会展示导入时的正文并提示当前内容已改变，需要重新核对。
- 单条记忆移入回收站会保留原文依据与历史，确认恢复后可继续使用；整空间删除仍会连带清除原文、历史、回收站和恢复记录。备份文件仍可能保留旧数据。
- 未勾选保留、旧版导入或手动／语音创建的记忆没有原文快照，会显示「未保留原文依据」。无法从文件名凭空还原；本阶段未提供给旧记忆补挂原文或替换原文的入口。

整理阶段的来源引用绑定当前会话和空间，有效期 1 小时；最终导入预览仍为 10 分钟。原文变更需要重新生成候选；过期则重新整理。来源文字与引用由服务端绑定，模型只返回编号，浏览器提交的自编摘录不会成为保存依据。

### 三种状态

| 状态 | 含义 | 问答行为 |
|---|---|---|
| 待核实 | 已保存，但尚未确认准确性或是否仍适用 | 可以作为参考，回答附待核实提示 |
| 有效 | 有修改权限的成员已核实，认为可以作为当前资料 | 优先提供给模型 |
| 过时 | 已不适用，保留用于回顾 | 默认不提供给模型 |

新建、语音保存和导入候选默认待核实。旧数据库的共同记忆也迁移为待核实，不把过去的“确认保存”追认为事实核实。有效不代表 AI 证明客观事实，只表示成员已做核实。

在后台编辑共同记忆或导入候选时选择状态。首次标记为有效／过时，以及切换到这两种状态时，需填写核实依据或过时原因；沿用已有状态时保留其说明。状态修改遵循已有正文修改权限，只读成员不能修改。保存仍须预览与明确确认。

修改已保存记忆的正文或事件日期后，会自动回到待核实，即使同时选择有效也不会沿用旧结论。核对后再次编辑状态并确认即可设为有效。所有变更进入现有修改历史，记录修改人、时间、前后状态和说明；没有旧状态字段的历史记录会显示「当时未记录」。

列表提供三种状态筛选。文字问答勾选「同时检索过时记忆」可回顾旧记录；语音明确说「查询过时记忆」或「已失效／旧版记忆」也会包含过时记录。公开语音仍只读取全体可见资料，状态不会绕过可见权限。问答优先有效资料，待核实与过时资料附明确提示，原文不自动发送给模型。

仍未实现：自动事实核实、按日期自动判定过时、后台自动整理、活动时间线、向量检索、自动回查整份原文答题。下一阶段再按真实资料验收结果扩展。

## 完整空间备份与恢复

已支持管理员导出完整JSON备份；保留正文、来源、原文、状态、历史、角色、可见范围和替代关联。选择备份后先核对现有本机账号对应，预览并双重确认，恢复到新空间。原空间继续保留，详见 [备份与恢复说明](SHARED_BACKUP.md)。

## 误操作恢复

已支持单条共同记忆回收站、历史内容恢复和最近一次替代纠正；均先预览确认，保留原因、前后内容与权限检查。入口在记忆库及“备份与恢复 → 误操作恢复”，见 [操作说明](SHARED_RECOVERY.md)。
