# IP 名称、形象与主题

在「声音设置」顶部管理 IP。Mac 示例 `config/mac.json` 使用“爱凤同学”和紫金色；其他未配置的启动方案保持“小伴”、绿色和默认机器人。

## 使用步骤

1. 结束当前对话、播放、录音和声纹录入，关闭所有页面的语音唤醒。
2. 选择预设，或填写名称、形象与两种颜色。名称留空时使用“小伴”。
3. 点击「预览外观」，切到「陪伴对话」查看效果。预览不会保存，也不会切换实际唤醒词，后台明确显示当前生效的词。
4. 点击「保存并生效」。名称同时用于页头、对话标题、助手署名、欢迎语、照片提示和模型的本轮自称。
5. 其他已打开页面刷新后使用同一份设置。重启服务后保留。「取消预览／重新加载」恢复已保存配置。

名称与唤醒词是独立设置：名称可以自定义，实际识别只支持「爱凤同学」和「你好小伴」两套。保存成功后，下次开启语音唤醒使用所选的关键词文件；语音会话也返回实际关键词，避免界面显示与监听内容不一致。增加任意新唤醒词还需提供分词发音、核对词表并评测误唤醒和漏唤醒，不能仅改页面文字。

## 形象与动效

- 内置爱凤是从用户提供的 `memopal-demo/web/index.html` 中复用的简化 SVG 凤凰，保留原有图形和配色；不是照片中的官方原始 Logo，也不是完整角色表情模型。
- 自定义形象仅接收 PNG，建议透明背景，最大 1.5 MB、边长不超过 4096 像素。后端不接收外部图片网址、任意文件路径或上传 SVG。
- 无形象或加载失败时显示原来的机器人。上传图像有漂浮、对话呼吸和现有固定屏幕动作；它不会自动生成眨眼、口型或全套动作帧。系统开启减少动态效果时停止持续动画。
- 主色作用于导航、按钮、背景、文字等色彩角色，保持各角色的明暗关系；点缀色用于形象光晕。警告、错误和记忆状态仍保留语义色。自定义颜色并非逐像素替换，极浅的主色会按按钮与正文可读性调整明暗。

## 存储和边界

启动配置为 `appearance`：`preset`、`name`、`primary`、`accent`、`avatar`、`wake_word`。本地保存文件位于记忆数据库同目录的 `appearance.json`，优先于启动配置；上传 PNG 编码也在该文件。文件由既有 `data/` 排除规则保护，不提交 Git。

`GET /api/appearance` 返回设置和版本，`POST /api/appearance/save` 需提交当前版本；其他页面已修改时拒绝覆盖，先重新加载。保存使用原子替换。损坏文件不会在读取时被覆盖，而是提示并回退启动配置。

接口继续只允许本机及同源请求。IP名称不作为用户身份，不修改个人档案、声纹、团队账号、归属、成员范围或模型本地／云端策略。设置动作不录音、不播放、不申请权限、不调整音量。正在运行的监听会话会阻止保存，避免中途更换实际唤醒模型。

## 本轮验收与后续实测

已使用临时数据库验证保存／重载、留空名称、无形象回退、取消预览、同步名称和文字回答自称。后端测试覆盖版本冲突、保存失败保持原配置、非法输入、同源限制和活动语音保护；前端检查覆盖迟到状态不覆盖新设置。实际本地 KWS／VAD 成功加载“爱凤同学”发音配置，未输入音频。

后续真人语音验收：开启唤醒，说「爱凤同学」，等进入收听后问「你叫什么名字」；再检查插话、噪声、不同距离、同音词误触发。加载成功不等于真实唤醒准确率已通过。本轮保持当前音量，没有语音播放。
