### 本轮重试流程的使用

刷新网页后开启声纹自动识别。普通语音问题遇到相似度不足、有效语音不足或候选太接近时，页面先提示重新识别，结束该轮诊断并提供按钮。点击按钮后重新录制完整问题。匹配成功才进入正常问答。如需按访客聊天，可在个人记忆中关闭声纹自动识别。共同记忆语音沿用自己的说话人校验与锁定流程。

本轮前端逻辑回归与 6 项来源／HTTP 测试通过，浏览器验证新页面加载和模式入口跳转。真人重试、重录声纹与准确率对照仍需参与者完成。

## 按步骤推进

1. **收尾文字连续追问与澄清（本轮）**：活动查询后可追问携带物品、负责人；同名不同日期先选择；新话题、空间切换、权限变化清理上下文。临时库网页验证，不改变真实资料；语音入口暂不扩展。
2. **让答案依据看得明白（已完成第一版）**：在每条回答下区分“实际引用”与“检索候选”，展示状态、日期和来源；有归档原文则可点开，无原文如实标注。验收：能定位支持结论的记录，不把未引用候选误当证据，不越权展示。
3. **先接只读 Agent 工具（已完成文字第一版）**：提供白名单记忆查询、读取授权记录、当前日期时间工具；模型只提出结构化请求，程序校验参数、权限、次数与超时再执行。验收：换一种说法仍能选对工具；资料中的伪指令不能授权操作；失败可说明原因和重试。
4. **再接写入工具的预览与确认（已完成文字第一版）**：模型提出保存/修改候选，继续复用现有归属、可见范围、冲突、版本和确认机制。验收：未确认不写入，取消不写入，跨空间不写入，重复确认不重复保存，冲突时显示修改前后。删除能力单独验收。
5. **补统一诊断和独立评测（诊断与虚构文字评测第一版已完成）**：本人操作记录、预览/确认/取消关联、阶段耗时、异常筛选与导出已完成；Ollama按实际返回统计Token，缺失显示未知。后续继续记录每轮查询、澄清、调用工具与结果状态、耗时、失败/恢复；获取供应商实际Token用量，费用仅在已配置价格时估算。新增未参与调参的问法，检查引用正确性、无答案拒答和权限隔离；不把缺失用量显示成0费用。
6. **再扩大记忆与协作范围**：新旧安排替代关系与确认已完成文字第一版，继续完善冲突提示；在验证权限隔离后，把检索能力复用到个人记忆。跨电脑部署另做身份、会话、传输和访问控制设计。
7. **最后补语音和硬件验收**：在方便说话时，再测识别、追问口播、声纹、确认与打断；其后推进开发板、Wi-Fi音频和动作。文字验证不替代这些验收。

每一步完成代码、隔离测试、可复现文字示例和使用说明后再推进下一步。当前不需要更换大模型或新增硬件。

只读工具的实际使用方法、协议与验收边界见 [只读 Agent 说明](READ_ONLY_AGENT.md)。第4步已接入新增和修改预览，详情见 [记忆预览确认](CONFIRMED_MEMORY_TOOLS.md)。第5步的统一诊断第一版已完成，见 [工具诊断](AGENT_DIAGNOSTICS.md)。已完成16题新虚构资料首轮与修复回归，见 [文字评测](AGENT_TEXT_EVALUATION.md)。新旧记忆替代关系已完成文字第一版；下一步收集真实资料人工反馈，语音另行验收。
