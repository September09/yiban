# 统一诊断总览（文字第一版）

入口：**运行诊断 → 统一诊断总览**。共同记忆先在“共同记忆”登录自己的账号并选择空间；也可以从问答下方工具记录点击“在统一诊断总览查看”。原语音阶段、声音诊断和回答反馈保留为下方折叠面板。

## 一轮看清五件事

1. **查询候选**：本轮检索返回哪些记忆，不代表被引用。没有执行检索、检索返回0条、记录未知会分别说明。
2. **实际引用**：只列出模型声明且编号已核对的引用，或程序定位的引用；未能核对时明确显示未知。普通模型聊天只有候选，不宣称已确认引用。
3. **使用模型**：记录实际尝试调用的模型名称、后端类型、本机／远端接口及调用次数。Agent调度和回答可能多次调用；调用尝试不表示全部成功。程序直接回答的日期／身份问题标明未调用模型。旧记录没有模型信息时不以当前配置补造。
4. **处理耗时**：整轮请求耗时与阶段耗时。阶段可能嵌套，不能相加；文字处理时间不等于语音播放时间，也不是独立性能基准。
5. **错误／结果说明**：区分无结果、连接失败、模型HTTP错误、输出格式问题、无效工具、超时、主动取消、权限或版本变化。错误采用固定分类和HTTP状态，不保存异常原文、请求头、密钥或服务URL。

下方分别展示实际引用、候选和已读取／提供给回答阶段的资料，含状态、事件日期、来源及原文入口。工具查询与真正读取分开记录：未读取的候选不能当作已用于回答。引用来自模型声明及程序校验，仍需人工核对事实及原文支持关系。

## 覆盖与保留范围

- **共同记忆文字问答**：开启Agent、只读Agent和关闭Agent的普通空间问答均写入现有agent-diagnostics.sqlite3；保留期14天，全机最多1000条，当前账号／空间最近50次。确认、取消、目标选择等原工具请求也在其中，可按关联编号追踪。
- 新增诊断仅持久保存记忆编号／版本、查询和读取标记、引用关系、模型、阶段、耗时及错误分类，不保存问题、回答、记忆正文或完整原文。本人在本页刚问的问题可在内存中用于定位；刷新后按时间和轮次编号查找。
- **查看历史诊断时**：后台重新检查成员资格、每条记忆当前可见范围及版本。已删除、移入回收站、不可见或版本变化的记录隐藏正文和编号，显示原因，不把当前内容冒充当时依据。管理员也不能从此入口读取其他账号的请求。
- **个人记忆查询与普通对话**：仅保留本页面最近20轮，刷新、切换档案后清空；个人记忆刷新／修改／删除时清空这些本页轮次。个人档案选择仍不等同于账号认证。诊断不会把资料另存入浏览器长期存储；原聊天历史仍按原有规则保存。
- 普通模型聊天的长期记忆只记为候选；日期和身份等明确由程序直接处理的规则回答可标为0引用。个人“记住／忘记／你记得什么”等旧指令尚未提供完整资料清单，不能把未知清单推断为未读记忆。
- 旧工具记录没有候选编号、模型或引用信息的字段显示未知，不能补造。日志未能保存时明确提示，请以原操作结果、记忆列表和修改历史为准。
- 本轮验证以文字为主。录音、声纹、播放、系统音量不属于本次验收；原语音面板继续负责这些环节。主记忆结构、声纹、模型选择和网络设置不因总览而更换。

## 怎么用文字测试

1. 在测试空间导入两条虚构资料：“蓝鲸活动十点在图书馆北门集合。”、“蓝鲸活动由乙负责接待。”
2. 提问“蓝鲸活动几点在哪里集合？”，再进入总览，核对候选、读取和实际引用，不要把候选数当成引用数。点击原文摘录，对照原始文字。
3. 在没有资料的测试空间提问，确认候选0、引用0；未调用模型时明确标记，并说明无相关资料属于正常结果。
4. 在普通聊天问“今天几号？”，应显示程序处理、未执行长期记忆检索、0引用、未调用模型。
5. 在个人档案保存虚构偏好后换个说法查询，核对实际引用；普通聊天同一偏好只列候选，不冒充已确认引用。
6. 修改或撤销已引用资料，再刷新总览，确认旧正文及编号被隐藏。用另一个账号查看，不应看到前一账号的记录。
7. 故障模拟使用隔离模型服务和测试数据库；检查HTTP错误、连接失败、超时与取消，不停止日常模型、不修改真实服务地址。

自动测试：`./.venv/bin/python -m unittest discover -s tests -p test_diagnostic_overview.py`；前端：`node tests/check_frontend.cjs`；全套：`./.venv/bin/python tests/run_all.py`。

## 代码对接

- yiban/conversation_diagnostics.py：请求内的安全模型信息、错误分类、阶段和私有记忆编号收集；公开轮次接口不返回记忆编号或正文。
- yiban/memory/agent_audit.py：原诊断库追加安全元数据，读取时按当前权限和版本还原可见资料；不新增主业务表。
- POST /api/shared/diagnostics/overview：需要Bearer账号令牌与space_id，只返回本人当前空间记录。权限变化后拒绝迟到结果。
- static/diagnostic-overview.js：统一展示、范围与异常筛选、本页文字轮次、身份清理和原文入口。
- static/shared.js、static/personal-retrieval.js、static/app.js：共同、个人及普通文字请求关联；不增加外部工具调用权限。
