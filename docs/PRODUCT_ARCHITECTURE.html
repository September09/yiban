忆伴：能交流，也能一起记住

面向家庭、团队和组织的人工智能陪伴产品，以爱凤 IP 为实验方向。当前运行在 Mac 浏览器中，界面和唤醒词仍叫“小伴”；主要交互是语音，网页承担体验入口与后台管理。

一轮交互，经过五个部分

本机基础版已接入 多人连续使用仍需验收
01 · 输入
你表达需求

文字、说话、按需拍照；后台添加聊天记录和活动资料。ReSpeaker USB 可作为音频入口。

02 · 理解
听懂与识别

唤醒、断句、语音转文字；声纹提供档案候选，不确定时按访客。照片按需进入看图模型。

03 · 调度
程序检查与安排

区分普通聊天、查记忆、写入预览和固定动作；维护会话、当前时间及打断状态，检查权限。

04 · 思考
模型结合记忆

只检索当前档案或当前账号可见资料。模型生成回答或提出工具请求，程序校验后执行。

05 · 输出
回应并可追溯

文字、语音朗读、屏幕表情／动作。记忆回答可看引用与候选，新增或修改按流程确认。

保存、修改、恢复、替代纠正等受控操作：先展示影响与范围，再由人确认。模型的建议和资料里的文字不能代替授权。普通对话中明确“记住”的个人新事实，沿用现有直接保存／冲突预览规则。

浏览器通过本机 HTTP 接口访问 Python 服务。唤醒／断句使用 Sherpa-ONNX 与 Silero VAD；语音识别为 SenseVoice INT8；声纹独立匹配，普通个人档案选择不构成登录认证。服务端用会话版本、权限、记录版本和取消令牌控制读写。

记忆是产品的核心

个人记忆

本轮接入语义检索

每个档案独立保存、检索、导入导出和修改历史。查询个人记忆时展示模型声明引用与其他候选；没有依据就提示。普通聊天展示本轮检索候选。

个人记忆目前没有待核实／有效／过时的状态字段；已保存不代表已核实。普通档案隔离用于本机体验，不能替代账号权限系统。

家庭／团队共同记忆

已接入受控流程

独立空间账号、管理员／编辑／只读角色；每条资料可指定可见成员和修改策略。支持状态、日期、原文依据、历史、导入、备份与恢复。

回收站、历史内容恢复、末端替代纠正均先预览确认。声纹不授予共享权限；普通个人聊天不会自动读取共同空间资料。

短期对话与长期记忆分开：普通聊天每轮发送最近16条消息，浏览器按档案保留最近30条文字。长期记忆按问题检索，每人／每空间最多200条；个人本轮最多取8条以内、合计2200字，不是把全部资料一直塞进上下文。

SQLite主库是事实来源；向量缓存为可重建的派生索引。个人索引命名空间 personal:档案ID，共同空间为 shared:空间ID。候选先按档案／权限筛选，再编码；按版本与正文哈希拒绝旧索引。记忆变化会触发重新查询，取消或迟到结果不进入其他档案。

模型与存储怎么分工

回答模型

本机 Ollama：Qwen2.5 3B。负责组织语言和提出受控工具请求。智谱、百炼兼容接口可切换，真实账号参数、用量与费用仍需验收。

检索模型

本机 Qwen3-Embedding 0.6B，配合文字排序，理解不同问法。不可用时回退有门槛的文字检索，不扩大到其他档案或空间。

看图与朗读

Qwen2.5-VL 3B处理明确拍下的照片；Mac系统语音负责朗读，可选音色和语速。不是持续视频感知，也不代表已有情绪识别。

存储用途
主SQLite数据库个人／共同记忆、档案、声纹特征、共享账号与会话、成员权限、历史、原文、替代链、回收站和恢复记录。
派生向量SQLite向量、资料编号、版本与哈希；不存记忆明文或查询历史，仍属于本机派生数据。
诊断与反馈SQLite本人工具操作诊断；用户明确提交的问答反馈与权限内快照。
浏览器本地与本机JSON按档案保存普通文字聊天历史；本机保存音色与语速偏好。共同空间资料不写入个人聊天缓存。

使用云端回答模型时，本轮问题与相关资料会发给配置的服务；向量服务目前限定本机。日期时间读取电脑时钟，尚无天气、新闻和通用网页搜索。

接下来你需要准备什么

  1. 现在先准备真实文字资料：给甲、乙各5–10条不同的偏好、习惯或活动信息，标明归属；再给出希望系统答对的问题及参考答案。先用你愿意用于测试的资料。
  2. 核对本轮体验：选对应档案，在“个人记忆 → 查询个人记忆”换几种问法，检查引用、无答案提示及甲乙隔离。把答错的问题和正确依据记下来。
  3. 方便讲话时再配合：甲、乙及未登记访客交替，测试声纹、唤醒、插话与回声。文字测试不能代替这些验收。
  4. 硬件阶段协调同事：确认板卡及加速芯片准确型号、系统镜像、驱动和麦克风固件，提供远程调试条件，再逐项适配。

代码侧建议下一步：个人记忆状态与疑似冲突提示 → 真实资料独立评测 → 回收站专门备份和清理。是否切换云端、开放多电脑或接实体动作，可等这些基础流程稳定后决定。
