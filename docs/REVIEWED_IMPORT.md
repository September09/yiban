# 已审阅资料导入包

用于将已经人工整理的候选正文、日期、状态和精确原文依据带入现有确认流程，避免重新AI提炼。入口：共同记忆 → 资料导入 → 已有逐条审阅结果？读取审阅导入包。普通原始资料仍使用原来的文件读取／整理入口。

每包最多40条候选、10份文字来源，原文合计30000字、文件4MB。大批量资料先分包。选择文件只生成内存中的候选与原文引用，不写数据库，不创建团队，不改变账号、可见范围或修改权限；仍须核对当前空间和表单范围，再预览并勾选确认。仅确认后的新增记忆进入批次管理，原去重、冲突提示、版本核对和回收站流程保留。

包格式为 `schema: yiban.reviewed-materials.v1`，包括 `batch_name`、`sources` 和 `items`。sources每项含name、text和原文UTF-8的SHA256。items每项含review_key、content、event_date、status、status_reason、source_note、source_index、ranges。ranges是来源text内的Unicode字符起止位置及精确text；校验摘要和摘录一致后才生成现有evidence_ref。摘要只检查传输一致性，不能证明来源真实或事实正确。文件中即使含scope_hint也不能授予权限。

日期只接受完整YYYY-MM-DD或空字符串。仅月份、学期、范围或未知日期需在正文／来源说明里保留原表达，不擅自填成某一天。状态valid／outdated必须有说明；用户确认存储不等于核实事实。

读取包会把其候选勾选，方便再次核对；必须点击最终预览、勾选确认并点击导入，才会写入。默认勾选保留原文，完整文字只给作者及管理员，可见成员只读对应摘录。原文变更会清理候选，需重新整理。切换空间、退出或取消后，迟到的读取结果不能恢复旧资料。

`POST /api/shared/import/reviewed` 仅在当前已认证空间、非只读成员内执行；不接受文件路径，不调用外部模型或网络。原始 `yiban.article-memory-review.v1` 审阅JSON不直接接受，必须先转换并核对建议选择。

审阅建议与最终导入分别验收：读取／预览不写库，确认才写；再次加载同包应去重；越权不能读取原文或引用；原文hash及摘录不匹配拒绝。每份真实资料的内容、题目和本地报告保留在data/或.runtime/，不提交Git。真实资料评测应冻结题目与期望，保留首轮失败，不能标为虚构数据或把回归称为独立盲测。
