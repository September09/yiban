# 对话页自动查询个人与团队

刷新后默认选择“自动查询个人与团队”。先选择自己的个人档案，再登录空间账号，回到陪伴对话直接输入问题即可。无需手动选团队空间，也无需在个人/共同记忆之间切换；一次问题可以同时询问个人偏好和班级事实。未登录空间账号时沿用个人对话，团队记忆不会被读取。个人档案与空间账号仍是独立身份，选择同名档案不能代替团队登录。

自动查询覆盖当前个人档案，以及登录账号已加入的家庭/团队空间。先按成员角色、指定成员/全员可见、状态筛选，再送给本机检索和回答模型；其他个人档案、未加入空间、不可见记录、回收站均不能进入候选。回答依据会标明个人或具体空间，显示实际引用、状态、日期、来源，团队原文摘录仍按原权限按需读取。

一个问题命中多个团队且指向不明时，先选择要问的团队。明确问“分别”的问题可按来源分开回答，统计也按个人及各团队分别列出，不把不同团队或个人记录直接相加。短期追问仅在本页会话内衔接，上轮问题只作检索背景，不能代替本轮资料。空间内容/成员权限变化、账号失效、个人档案切换时，旧话题失效并清空当前团队显示。每轮及返回前重新核对权限；迟到响应不能重新显示旧账号资料。

只有当前档案的ID与本轮问题发给自动接口，不携带个人聊天历史。团队相关的提问、回答、依据和令牌只在页面内存；不会复制为个人记忆、存进原个人聊天历史或写入团队资料。未登录团队时的个人聊天仍沿用原来的浏览器历史。新对话只清当前显示与短期话题，不删除长期记忆。刷新需重新登录空间账号。

自动文字接口只读，保存、编辑、替代和删除仍使用原后台的预览确认。包含个人档案的自动查询仅允许本机模型；切换到云端时会明确阻止，不悄悄发送个人资料。不含个人档案时，云端仍只可使用当前空间账号可见且全员可见的资料。文字模式不自动朗读或录音，音量不变；独立共同记忆语音入口及个人朗读选择保留。

## 活动次数怎样计算

“聚餐过几次”“篮球比赛打过几场”等可识别的计数问题，会扫描完整的当前可见资料快照，按日期、活动线索和范围分组，程序计数；不使用最相关几条的命中条数当总次数。当前有聚餐、生日会、篮球比赛、徒步的有限文字规则，不是对任意活动的完整语义理解。

同一范围同日同类报道保守合并，明确的预告、计划、取消、未来日期以及仅写总次数而无逐场依据的汇总不单独加次数。无日期的补充记录可在活动名称唯一吻合时合并；无法排除重复时独立列出待核对，不能直接与已知日期次数相加。回答区分“整理出几组记录”与“可确定区分的活动下限”，保留待核实状态，不宣称实际全部次数。同日有多场活动时可能低估，仍需核对。年月和明确日期范围支持过滤；更复杂筛选和缺失的活动日期需要补充资料。

团队活动记录不证明每位成员出席。问“我参加过几次”时，只用当前个人档案的相应参与记录；不能把所有班级活动都当作你个人参加。个人与各团队分别计数，不跨范围直接合计。

## 手动范围与验证边界

仍可在顶部选择“仅个人记忆”或“指定共同记忆空间”。指定空间继续走原只读查询与活动选择流程。

测试包括：独立数据库的权限/会话撤销/个人隔离/云端限制/只读检查、超过普通检索条数的去重计数、日期范围与个人出席口径；真实119条副本加虚构个人偏好的联合文字回归；隔离Chrome中先选个人再登录团队，不选空间直接联合提问、引用双方来源、聚餐计数、手机布局、退出清空和零音频请求。回归不是独立盲测，不代表每条记忆或所有问法都验证过。真实资料报告留在Git忽略目录。
