## Serena声音稳定方案（2026-11-16，v39）

按用户要求，当前本机偏好固定为Serena，保留后台预热和常驻进程。普通对话、记忆朗读与再次朗读采用同一稳定生成策略，不按情绪自动切换说话人。音色下拉项仍保留供用户今后主动选择。

- 生成策略集中在yiban/audio/qwen_profile.py：温度0.5（原0.9）、top_k=20（原50）、top_p=0.85（原1.0），每个请求固定MLX种子42。自然平稳的统一风格指令适用于所选说话人；这会减少随机波动，不等于声纹克隆或保证所有文本音高完全相同。
- 已完整到达的100字以内短回答尽量一次合成；流式长回答等待完整句意、优先至少24个非空白字符，并在约100字处按自然边界分段。后端按完整句子装入120字左右片段，避免二次逐句重启；保护数字和比分不在分段边界拆开。超长单个英文/数字串可能保留完整而超过名义上限。
- 句间预取和取消协议保留；同一进程重复请求不重载模型。该版HTTP仍等一个片段完整WAV再开始播放，因此减少拼接会增加首播等待，并未实现单次合成音频连续推流到浏览器。
- 17项Qwen／常驻／分段检查、5项声音偏好检查与4组相关前端检查通过。固定文本跨其他请求重复生成，得到字节完全相同的WAV；只能证明这条文本在当前环境下可重复，不能代替人的听感判断。

## 同次合成连续播放（2026-11-16，v40）

当前Qwen对话采用“一条完整回答 → 一次模型生成 → 连续PCM帧 → 浏览器连续播放”。不再用多个短文本请求模拟流式。记忆回答仍先完成检索、权限与事实引用校验，再交给语音；不会朗读未经校验的模型草稿。系统声音等不支持PCM的引擎继续使用原WAV路径。

保留Serena、后台预热、常驻进程，以及默认种子42、温度0.5、top_k20、top_p0.85、重复惩罚1.05。单次连续朗读限制1200字、合成限时240秒；过长或传输不完整明确报错，不静默换声音或再拆成多次请求。取消会停止已排程音频、关闭输出流，并清理工作进程尚未消费的帧；正常取消后模型继续常驻。输出设备沿用现有校验，浏览器支持时直接送到所选输出，兼容路径才使用MediaStream桥接。

「声音设置 → 回答音色与语速 → 高级：声音稳定性」可修改种子、温度、top_k、top_p，先试听再保存。恢复稳定设置只改页面草稿，仍需点击保存。参数保存到本机已忽略的声音偏好文件，下一次朗读取一次快照，重启后保留；改变参数不会重新加载模型。较高随机性通常带来更多语气变化；固定种子用于复现，不保证不同文本或模型版本的声线完全相同。重复惩罚维持1.05，不在页面暴露。

同5条冻结回答的本机对比：v39完整WAV等待6.816 / 4.302 / 9.194 / 6.862 / 9.345秒，v40首批PCM为0.502 / 0.377 / 0.375 / 0.375 / 0.407秒。每条均为一次生成，完整音频长度与旧版一致；PCM整数差最大2个量化单位（两种保存方式的转换差异）。这些是热模型语音阶段实测，不包含文字模型处理，也不是延迟承诺。浏览器五问的独立端到端结果见本机 `.runtime/continuous-speech-20261116/` 验收报告；首次播放为页面音频排程时间，未用外部麦克风测量物理扬声器延迟。
