# 资料来源与导入批次

入口：**共同记忆 → 登录并选择空间 → 资料导入 → 资料来源与导入批次**。沿用现有标签，不增加一级页面。先用文字验收，不需要录音或播放。

## 导入并查来源

1. 在下面的资料整理表单填写“本次导入批次名称”，添加文件或粘贴文字，核对读取结果。空名称保存为“资料导入”，列表以时间与唯一编号区分。
2. 生成候选，逐条核对内容、日期、状态、可见成员和修改权限。需要以后查原文时，勾选“保留原文依据”；未勾选不会归档原文。
3. 查看最终导入预览，确认后才新增记忆、批次及关联。跳过的重复记忆不归入这个新批次，也不受其撤销影响；整批重复不会新建空批次。
4. 点击上方“刷新导入批次”，可以查名称、编号、导入者；点“查看本批记忆与来源”查看状态、事件日期、作者、范围、修改权限和来源说明。
5. 有依据时，可查看原文摘录。整份文字快照只给仍在空间内的作者和管理员查看；其他可见成员只读对应摘录。来源文件名从服务暂存的原文引用取得，不依赖模型生成的引文。

原文是导入时读取并人工核对的文字快照，可能包含 OCR 和人工修订，不保留原文件、图片或附件。引文相符不能证明摘要或原资料中的事实正确。未保留依据时，系统不能从文件名、来源说明还原原文。已修改正文会提示依据仍对应导入时内容。

## 预览并确认撤销

1. 打开批次详情，填写撤销说明，再点“预览撤销本批未修改记忆”。
2. 预览区分“将移入回收站”和“本次保留”，展示内容、状态、日期、来源、作者、范围、修改权限及保留原因。
3. 两项确认均勾选后，才可点“确认移入回收站”。只撤销确认时仍保持导入版本、可管理且未关联新旧安排的记忆。
4. 导入后已修改（包括范围、日期、状态修改）、已恢复、关联替代链的记忆保留；已在回收站的不重复处理。新旧安排需使用原有替代纠正流程。
5. 刷新批次可看到在库／回收站数量及撤销说明；回收站记录仍可由有权限账号查看归档原文。误撤销可到“备份与恢复”逐条预览恢复。恢复后标为待核实，保留批次关联，且不会再次当成未修改的导入记录撤销。

撤销只对本批实际新增的记忆生效，正文、原文和全部修改历史在回收站保留，不参与正常问答。回收站最多100条或24 MB；预估整批会超限时拒绝，不能静默只撤销一部分。事务失败整批回滚。

## 权限、并发与备份

- 管理员和本批导入者（仍为编辑成员）可发起撤销；只读账号和其他编辑成员不能撤销。各项读取在后端再次检查当前成员和单条可见范围。
- 非管理者只看到可见记忆的数量与来源，不获得不可见条目、回收站、撤销审计或自定义批次标题；列表使用通用批次名称，避免标题泄露其他资料信息。
- 预览10分钟有效，绑定具体登录会话、空间版本与完整快照；改原因、取消、退出或资料／成员变化后要求重新预览。确认只执行冻结的清单，忽略客户端另传的目标或正文。
- 确认结果持久保存；响应丢失后用原预览重试不会重复移除，服务重启后也可以返回已经执行的结果。再次执行仍复核当前会话、成员和管理权限。
- 新增SQLite表：shared_import_batches、shared_import_batch_items、shared_import_undos。原文继续保存在shared_evidence，移入后在shared_trash快照中；不另建向量数据库或改个人声纹数据。
- 空间JSON备份新增可选batches字段，保留**仍在正常库中的记忆**与批次关联。恢复时重建批次和记忆编号，保留导入时间、来源及初始版本；没有batches字段的旧v1备份仍可恢复。回收站、独立撤销审计以及只剩回收站记录的批次不包含在空间JSON中；需要时先恢复相关记忆再导出。
- 升级前已存在的记忆不推测所属批次，继续通过原记忆库、来源依据、历史和回收站管理。创建、替代、个人记忆JSON导入不算资料导入批次。

## 文字验收

使用单独测试空间，粘贴两段虚构文字：

```text
蓝鲸测试活动于2026年11月21日上午十点在图书馆北门集合。

乙负责接待，甲负责物资。
```

命名批次并勾选保留依据，导入后应有2条待核实记忆；查看完整原文应看到两段。问“蓝鲸测试活动几点在哪里集合？”应据资料回答并注明待核实。仅预览撤销时记忆仍在；确认后在库0条、回收站2条，原文与历史仍在，再问不应引用这两条记录。另测先修改一条再撤销，预览只允许移入另一条，并明确保留原因。

后端专项：`./.venv/bin/python -m unittest discover -s tests -p test_shared_batches.py`。
全项目：`./.venv/bin/python tests/run_all.py`。测试使用虚构资料和临时库，不替代真实成员权限及语音设备验收。
