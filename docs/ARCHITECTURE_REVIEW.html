判断

适合继续采用模块化单体＋本地SQLite，把核心业务路径收敛清楚。已有模型适配、权限、精确引用、确认写入、语音组件和多轮工具查询。当前主要成本来自新旧记忆路径并存、提取与问答职责边界、资料版本追踪，以及真实评测和维护工具的覆盖。

继续扩功能前，先确保“这段资料从哪里来、谁能读、有没有核实、为什么能回答、修改后如何回退”在所有入口使用同一套规则。

层当前承担的职责需要收敛的边界

能力适配本地／兼容云端LLM、ASR、TTS、唤醒、声纹、动作。需要统一资源调度、超时／取消和健康状态；MD提取不能拖住正在对话的人。

资料进入和使用的流程

上传UTF-8 MD→ 本机分段提取cards→ 原文段落编号校验→ 私人内容分列→ 脱敏正文与来源全文→ 用户预览确认→ 待核实新版记忆→ 人工核验→ 有权限的检索与回答

原文证据由程序按有效段落编号还原，不让模型生成的“引文”代替真实原文。数字、任职、比分的结构化字段另外校验；不完整时降为带原文的候选并说明待补核，不冒充确定事实。提取和权限是两个独立步骤，模型不能决定owner、公开范围或是否核验通过。

问答继续采用简单问题快速处理、复杂问题受控只读工具查询；每轮重新检查权限、版本、取消与引用。当前本机向量开关关闭，不能把现状描述成所有查询都依赖向量；只读工具通过受约束JSON选择，并非所有供应商原生tool_calls已统一。

昨天JSON与正式结构

cards字段新版承接
type / title / what / detailrecords中的type / title / summary / detail。
who_namesentities与participants；名字不自动变成登录账号，不自动跨文章合并同名人物。
when / when_precision事件时间、精度与依据。缺年份保持未知，不用发布日期代替发生时间。
emotion / tagsemotions / tags，仍是候选描述。
quote / source程序还原精确原文，保存来源全文SHA256、字符位置与摘录。
新增事实字段任职、数量口径、比分等进入已注册的fact结构；格式或依据不足则留待核对。
confidence / needs_review / owner / visibility不作为真实性或权限依据。由人工核验状态、当前账号、真实成员权限和保存预览决定。

正式协议继续是yiban.memory-candidates.v2，复用现有数据模型与校验器，不另建一套MD专属记忆数据库。

按优先级完善

优先级工作验收目标
P0 · 本轮统一资料口径；MD候选、私人段落和全文脱敏；旧图片批次退出查询。确认前零写库；私人段落不残留在公共来源；旧图片记忆在历史入口及自动查询也不可被召回，历史可追溯。
P1统一查询服务与策略。对话页、专门问答、工具和语音读取共用权限、资料版本、统计与未知规则；逐步收敛旧路径，减少规则散落。
P1提取任务、模型、提示词与来源的版本追踪。清楚记录用什么模型、规则和源版本生成候选；可重提取对比，不覆盖已核验记忆。当前草稿只在内存保留，重启／超时不能恢复任务。
P1数据生命周期、备份和恢复。新版空间连同原文、事件、权限映射、历史与查询排除状态可完整备份恢复；引入显式数据库迁移与版本回滚。当前仍主要依赖SQLite一致性备份，旧版导出恢复不能当作新版完整备份。
P1独立质量评测与持续回归。分别量化提取覆盖、隐私遗漏、事实正确、引用完整、未知拒答、权限和等待；新题与修复回归分开。原30项与补充2题不能拼成“本版30/30”。
P1共享资源与等待治理。对话优先、提取可暂停、模型和语音队列可取消，记录首字／首音／整轮耗时。当前MD模块限制并行提取，但尚无跨所有模块的统一模型调度。
P2可安装、可升级、可诊断。干净电脑可复现安装，依赖与模型有版本清单；隐私安全的诊断包只含必要元数据，避免保存原始私人输入。
P2远程与硬件阶段。在远程访问前补认证部署、TLS、会话与操作审计；当前仍按本机原型使用。Windows、多人声纹和真实回声／打断需独立实机验收。

本轮验证边界

相关225项后端检查及两组前端逻辑检查通过；真实本机9B与Chrome用虚构MD检查候选、私人段落和脱敏全文，保存预览后取消，未入库。扩展自动上传受限，实际浏览器用粘贴入口；文件选择读取由前端检查覆盖，尚不能称文件选择器全程实测。旧图片119条停查后，实际历史提问返回0条依据。

下一批建议

  1. 用3–5篇未参与修复的MD验收自动提取与人工审阅，重点检查数量口径、私人段落及漏提取。
  2. 把问答入口收敛到同一查询服务，同时建立新版空间备份与恢复演练。
  3. 邀请3–5人独立完成登录、添加、核验、提问和查原文，再依据实际卡点优化界面和等待。
自动提取是候选准备，不是事实认证；全文脱敏仍需人检查。当前草稿30分钟失效，一次最多5篇、每篇24000字，段落数量有上限，格式失败不会写入记忆。模型可能漏提取或产生重复口径，不能把“JSON校验通过”视为内容完整或真实。
