# 工具诊断与操作记录

更新：2026-11-10。适用于后台的文字 Agent 问答；语音仍按原流程运行。

## 从哪里看

1. 打开助手，在「家庭与团队 · 后台管理」登录自己的空间账号并选择团队或家庭。
2. 保持「自动选择记忆工具」开启，输入问题，或者提出保存、修改要求。
3. 展开问题区下方的「我的工具记录（当前空间）」。处理期间可刷新查看；面板打开且问答进行中时每秒更新一次。
4. 展开单条记录查看阶段、耗时、模型调用次数、Token 用量和工具结果。点击「仅看异常」筛选需要处理的记录。
5. 遇到问题，可点「导出最近50条记录」。下载 JSON 包含当前空间、本账号最近最多50条记录，不受“仅看异常”筛选影响。

页面刷新后需要重新登录。登录同一个账号、选择同一个空间，即可继续查看保留期内的记录。升级前的操作不会补造记录。

## 如何理解结果

| 显示 | 含义与处理方式 |
|---|---|
| 处理中 | 看当前进行中的阶段：理解意图、检索、等待模型首段输出、生成结果等 |
| 等待核对确认 | 当时只生成了预览；结合相同关联编号的后续记录判断是否保存或取消 |
| 等待选择记忆／需要澄清 | 按回答提示选择具体记录，或者补充活动和日期 |
| 已保存 | 确认接口已返回保存成功；修改内容和版本仍以共同记忆修改历史为准 |
| 已取消 | 本次取消已生效，取消本身不会写入预览内容 |
| 请求未通过 | 可能缺少确认、草稿已取消/过期、版本或权限变化；先核对提示，必要时重新预览 |
| 处理失败／超时 | 查看失败步骤，检查模型服务，再重新发送更明确的请求 |
| 服务中断／结果未记录 | 未获得可靠的最终记录；先核对记忆列表和历史，不直接重复提交 |

关联编号用于串起“请求 → 选择目标 → 生成预览 → 确认／取消”。输入了新的问题会产生新的编号；未自动关联无关的重试。编号显示前8位，导出包含完整值。

步骤可以嵌套，例如“理解操作意图”包含“等待模型”和“生成模型结果”。不能把所有步骤耗时相加当作总耗时。记录数量与异常数量只描述当前最多50次请求，不表示检索命中率或回答准确率；待确认、澄清和主动取消不会计作异常。

## 用量与费用

- Ollama 返回 `prompt_eval_count`、`eval_count` 时，分别累计为输入和输出 Token。同一次调用的流式统计只计算一次。
- 每条操作记录标明模型调用总次数和实际返回用量的次数。只有全部调用都有统计时才显示“完整用量”；部分返回显示“部分”，没有返回显示“未知”。
- 确认与取消直接走程序校验，通常无需模型调用；显示0次不代表所有服务都没有成本。
- 目前云端适配器尚未传回流式用量，显示未知。费用价格表、缓存计费和供应商账单对齐尚未实现，不显示“0元”冒充免费。

## 存储与权限

诊断使用独立 SQLite 文件 `agent-diagnostics.sqlite3`，放在配置的主记忆数据库同一目录，通常是 `data/agent-diagnostics.sqlite3`。不修改主记忆表；文件仅本机用户可读写。每次读写时清理超过14天的记录，全文件最多保留1000条；每个账号每个空间最多返回最新50条。

持久记录包含账号/空间内部编号、操作关联编号、时间、状态码、耗时、工具名、资料数量和统计用量。问答正文、记忆原文、录音、声纹、密钥、登录令牌、草稿令牌和异常原文均不写入诊断记录。关联草稿使用哈希摘要，短期保留；页面内存随退出/切换清空，不放入浏览器长期存储。

查看与导出均重新检查登录和当前空间成员资格，只允许查看本人记录；空间管理员也不能通过此入口读取其他成员的工具记录。撤销成员资格后不能继续读取该空间的记录。它不开放跨电脑服务。

这是用于排查的轻量操作日志，**不是与业务保存原子提交的、防篡改审计账本**。记录失败不会撤销已经完成的保存；界面会提示记录不可用。若保存后服务异常中断，最终结果需查记忆列表和修改历史。服务启动时，遗留的“处理中”标记为中断，不擅自认定保存失败。

## 代码对接

| 文件／入口 | 职责 |
|---|---|
| `yiban/memory/agent_audit.py` | 账号/空间过滤、持久记录、关联、保留期、日志故障隔离 |
| `yiban/conversation_diagnostics.py` | 每个请求的独立阶段计时与实际用量汇总 |
| `static/shared-audit.js` | 查看、实时刷新、异常筛选、JSON导出，清理迟到结果 |
| `POST /api/shared/agent/records` | Bearer登录令牌与 `space_id`；返回本人记录 |
| `/api/shared/agent/memory/ask\|confirm\|cancel`、`/api/shared/agent/ask` | 包装已有受控业务，响应追加 `diagnostic.available` 和记录编号 |

服务内部计时编号不作为公开能力令牌返回。2026-11-13起，普通共同记忆文字问答 `/api/shared/ask` 也接入这份日志。新增模型名称、接口类型、候选／读取／引用编号及版本和安全错误分类；不保存正文。普通个人聊天与个人查询仍只在页面内存展示。统一入口与权限、版本变化的隐藏规则见[统一诊断总览](DIAGNOSTIC_OVERVIEW.md)。原语音诊断保留。
