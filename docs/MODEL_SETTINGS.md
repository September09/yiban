# 模型切换、连接检测与同题文字对比

入口：顶部「模型设置」。这是本机助手的设备设置，所有打开的页面共用；不改变记忆归属、成员权限、声纹或系统音量。

## 保存和切换

1. 选择「编辑档位」：本机或云端。
2. 填写接口类型、服务地址、文字模型名称；视觉模型可以留空。
3. 按服务商选择思考参数：标准兼容、智谱关闭思考或百炼关闭思考；与服务商不匹配可能被拒绝。密钥一栏只填**环境变量名称**，例如现有智谱示例使用的 `ZHIPU_API_KEY`，不要填写密钥。
4. 选择「保存后的使用档位」。启用云端时须勾选发送确认，再点「保存并应用」。
5. 切换云端须已读取密钥；未配置时可以只保存云端配置并继续使用本机。新请求使用新设置；已经开始的整轮请求固定使用开始时的模型，包括多次 Agent 工具选择。没有自动跨本地／云端的故障备用路径。

本机档位只接受回环地址；云端档位要求远端 HTTPS 的 OpenAI 兼容接口。保存不会启动、下载或停止模型服务。原始配置仍是首次初始化和设置损坏时的回退来源。

设置保存在记忆数据库同目录的 `model-settings.json`，默认属于忽略的 `data/`。只保存模型配置和所选档位，不保存环境变量的值。文件采用临时文件替换，权限为仅当前用户读写；多页面修改通过版本号检测，旧页面需重新加载。重启后恢复所选档位。环境变量需由**启动助手的进程**读取，修改后应重启助手。

现有安全配置入口仍可使用 `start-zhipu.command` / `start-cloud.command`，交互提示隐藏密钥且不保存到文件。若已有本页保存的配置，重启后以本页保存档位为准，请在页面核对。密钥不要发送到聊天、写入仓库或填写进服务地址。

## 连接检测

检测的是**已经保存的当前编辑档位**，并非尚未保存的输入。云端须确认发送固定短句；不会携带聊天或记忆。

- 密钥配置：只检查指定环境变量是否存在，不把「存在」当成鉴权成功。
- 模型目录：本机 Ollama 请求 `/api/tags`，兼容接口请求 `/models`。401／403 明确失败。目录缺失、404 或未列出模型，不能认定能回答，继续以实际回复验证。
- 实际回复：发送固定连接短句，要求收到非空且正常结束的文字。空回复、截断、连接中断、HTTP 错误均不算通过。

显示各阶段状态、HTTP 状态和总耗时；外部错误正文不会原样显示，以免回显请求或凭据。检测设有取消时限，可以点「停止本次测试」。HTTPS 保留证书验证，不跟随目录请求的重定向转交密钥。

## 同题对比

1. 普通问题：手动输入问题，不带记忆和历史聊天。
2. 共同记忆：先登录并选空间，再选择该范围。先限定**当前账号有权查看且全体空间成员可见**的记录，再检索；指定成员可见、个人记忆和不可见资料不参与。
3. 点「预览将发送的问题和资料」，核对问题、模型、服务地址和候选正文、状态、日期及来源。
4. 勾选本次发送同意，再确认开始。本机与云端独立、顺序调用，使用相同的问题和资料快照；一边失败不会冒充成功或触发隐藏备用调用。
5. 共同记忆回答沿用现有引用编号核对与待核实／过时提示。模型声明的引用编号有效不代表结论已由程序证明，仍要核对原文。

预览有效10分钟，绑定登录会话、空间版本及模型设置版本，一次确认后消耗。每次调用前、生成后和交付前复核权限及版本；失去访问权或资料变化时丢弃结果。没有相关共享资料时两边都不调用回答模型。无密钥的一边显示未配置，另一边可以独立完成。

对比不执行 Agent 写入、不保存正式对话、记忆或反馈，不调用朗读。预览仅暂存服务内存，结果仅在页面内存；取消预览、离开模型页、切换空间／退出登录或本页观察到空间版本变化会清空页面。刷新后不恢复结果。其他页面的权限变化无法瞬时推送到已显示的浏览器，切换或刷新会重新核对。

耗时受顺序、预热、网络和模型负载影响，单题结果不是性能排名。首段文字等待和总耗时分别显示；仅展示服务实际提供的 Token 信息，不估造费用。

## 云端使用范围

启用云端后，普通聊天只发送本次输入，不自动带出此前本地历史；选中个人档案时提示切回本机或使用访客普通聊天。个人记忆模型问答只在本机档位进行。

共同记忆云端问答只检索全体成员可见资料；仍先检查当前账号的空间权限。云端暂不生成保存／修改／替代记忆的 Agent 草稿，请切回本机使用原有预览确认流程。已有确定性后台管理、历史恢复和确认入口保留。资料导入继续使用原来的单独「发送原文到远端」确认。

**全体成员可见是空间内的共享范围，不等于对互联网公开。** 用户仍需自行确认本次问题与共享资料适合发送给所配置模型服务。程序不能识别手动输入的文字是否来自私人资料。

## 开发接口与测试

- `GET /api/models/settings`：配置和环境变量存在状态，绝不返回密钥值。
- `POST /api/models/save`：配置版本校验、保存、切换。
- `POST /api/models/probe`：固定文字检测。
- `POST /api/models/compare/preview`、`confirm`、`cancel`：受控对比。

沿用回环监听和 Host／Origin 检查；配置属于本机设备设置，尚未提供远程设备管理员认证。共同记忆对比必须携带原有空间会话令牌，不能用声纹或个人档案代替。

测试：`python -m unittest discover -s tests -p test_model_settings.py`、`node tests/check_model_settings.cjs`，以及原有完整回归。测试使用临时数据库和模拟服务，覆盖保存／重启、正在运行请求固定模型、同意与密钥、401／404、截断、授权范围、确认前／两模型之间撤权、取消及迟到结果。真实云端服务是否可用仍需有效密钥单独验收。
