# 回答反馈与问题回放

适用于共同记忆的后台文字问答，包含默认 Agent 查询和关闭自动工具后的查询。

## 如何提交

1. 登录空间账号并选择家庭或团队空间，在「记忆问答」发送问题。
2. 完成回答后展开「评价这次回答」，选择回答正确、回答有误、遗漏资料或引用有误。
3. 可填写说明或正确答案。勾选同意在本机保存本轮问答、资料快照和反馈，再点击「保存回答反馈」。

入口在本轮回答后的10分钟内有效，与登录会话和空间绑定。资料变化后需要重新提问。新的问题会清空未提交反馈。新增／修改记忆的保存预览和失败结果不提供此入口。重复提交同一入口返回原反馈编号。

## 如何回放与复测

1. 保持当前空间账号登录并选好空间，进入「运行诊断」，展开「回答反馈」。
2. 点击记录，查看原问题、当时回答、实际引用与候选的记忆快照、状态、事件日期、来源备注及已归档原文名称。
3. 选择待处理、处理中或已复核，填写处理说明后保存。标记已复核必须填写说明。
4. 点击「把原问题带回问答」。有活动话题时同时补入当时的话题，点击「询问共同记忆」执行一次新查询，再回到反馈更新复核结果。

进度表示使用者的处理标记，不是系统自动判定答案正确。反馈说明不会自动改写记忆，实际资料更正仍使用原有预览与确认流程。

## 保存与权限

- 默认只在服务内存中保留最多128个、10分钟有效的反馈入口。明确提交后才持久保存问答和资料快照。
- 记录保存在当前记忆数据库旁的 `answer-feedback.sqlite3`，文件权限为本机用户读写，默认路径 `data/answer-feedback.sqlite3`。此目录被 Git 忽略。
- 每个账号只能查看本人在当前空间的反馈，管理员也不能借此查看其他人的记录。刷新网页后重新登录同一账号和空间可以继续查看。
- 仅显示当前空间本人最近50条，保存90天，全机最多500条，超限和过期记录自动清理。
- 回放重新检查成员资格、资料可见范围及版本。来源删除或不可见时隐藏整个问答、来源及说明。记录变化后，只有仍能查看历史的原作者或空间管理员能查看旧快照，其他成员需要重新提问。
- 保存的是该轮问题、回答及返回的记忆条目快照，不额外复制完整原文文件、图片或录音。原文名称与来源备注按当时返回的资料保留。
- 反馈写入独立于记忆正文。反馈保存失败可重试，不撤销原查询。原反馈入口在服务重启后失效，已保存反馈仍保留。

## 代码入口

| 文件 | 职责 |
|---|---|
| `yiban/memory/answer_feedback.py` | 会话绑定入口、明确提交、持久记录、权限核验、版本检查与清理 |
| `static/shared-feedback.js` | 评价表单、本人记录、回放、处理进度及带回问题 |
| `server.py` | 向完成的文字回答附加入口，提供 `/api/shared/feedback/submit`、`list`、`detail`、`update` |
| `tests/test_answer_feedback.py` | 提交与重试、会话／空间／账号隔离、资料变化、隐藏快照、处理版本和 HTTP 路由 |

## 验证范围

权限和状态使用临时数据库检查。独立虚构活动库以本地 Qwen2.5 3B 完成默认 Agent 查询、反馈提交、回放、进度保存、带回问题、刷新并重新登录后的记录读取。

第一版尚无批量处理、反馈分享、自动问题归因、自动答案对照评分或个人聊天反馈入口。
